SAFE SYSTEM MAINTENANCE

Analyze. Review. Repair.

Scan the local system for failed services, storage warnings and ZFS protection issues. Read-only checks run here; administrator repairs require an explicit terminal command. No generated shell code runs automatically.

Native ZFS scrubs may detect and correct errors when redundant copies exist. Single-copy ZFS detects corruption but cannot reconstruct missing data. Never run fsck on mounted filesystems.

Approved repairs use the Ubuntu terminal. Review the generated plan and type the exact confirmation for a named action. Package reinstalls, recursive deletions, disk formatting, and live-root rollback are never run by the AI.
